# boggle

终端 Boggle 单词查找器：在 4×4 字母棋盘上找出所有可组成的单词并计分。纯标准库。

## 玩法

```
python -m boggle                      # 随机棋盘
python -m boggle --board CATSXYZ...   # 固定 16 字母棋盘
python -m boggle --seed 42            # 可复现的随机棋盘
python -m boggle --min 4              # 只找 4 字母及以上
```

规则：字母上下左右（含对角线）相邻、可连成单词；每个格子每词只用一次；
`Q` 按 `Qu` 处理（经典 Boggle 规则）。

计分：3–4 字母 1 分；5 字母 2 分；6 字母 3 分；7 字母 5 分；8+ 字母 11 分。

## 设计取舍

- 内置约 280 个常用词（3–8 字母），做成 `WORDS` 常量：零依赖、开箱即用。
- 前缀剪枝：DFS 时一旦当前串不是任何词的前缀就剪掉，4×4 全盘搜索毫秒级。
- 默认用 `secrets` 生成棋盘（真随机）；`--seed` 时用确定性随机。

## 已知局限

- 词表很小，很多合法英文词不在里面——"小巧"的代价，加词直接改 `WORDS`。
- 只找词、不带计时/人机对战；Q→Qu 是硬编码约定。
- 固定 4×4 棋盘，不支持 5×5 Big Boggle。
